# 不做浏览器，Acuminata 站在浏览器外侧

Acuminata 的核心需求是给没有用户系统的小型视频站补上"看过什么"和"可能还想看什么"。这两件事都发生在内容身份与偏好聚合这一层，与渲染网页无关。我们认真考虑过把 Acuminata 做成自带浏览器的产品，最终放弃：那会把它从用户现有浏览器的互补品变成替代品，代价是与 Chrome 争夺默认浏览器位置，而换来的只是省掉一个扩展。决定：保留 Chrome 扩展作为捕获层，Electron 只做聚合与推荐。

## Considered Options

- **Electron 内建浏览器**（`WebContentsView` 阅读面板）：只能捕获用户在 Acuminata 里打开的那几个页面，等于没有捕获。成本低，收益接近零。
- **Acuminata 自己就是浏览器**：捕获完整，但 Electron 无法胜任通用浏览器——没有扩展生态、没有 Widevine（Netflix / Spotify 打不开）、没有移动端、没有自动更新。现实路径是 fork Chromium，以年和团队计。
- **读浏览器自身的 History 库 / OS 可访问性 API / 本地代理**：不需要扩展就能拿到访问列表，但拿不到停留时长、镜像跳转和页面字段，而且无法在写入路径上做判定。`gencert.js` 是这条路的遗留。
- **保留扩展**（选中）：用户已经在那几个站上，扩展恰好在正确的时刻拿到正确的字段。
